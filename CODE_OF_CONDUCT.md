# Code of conduct

Be kind, be specific, assume good faith. Criticize code and ideas, not people. No harassment, no discrimination, no
personal attacks, no publishing other people's private information. Keep discussions on topic.

The maintainer can edit or remove comments, close issues and pull requests, and block people who do not follow this.
Report problems by opening an issue that does not name the person, or through the private reporting described in
SECURITY.md.
